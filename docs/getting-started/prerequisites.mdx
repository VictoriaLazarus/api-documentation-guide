# Prerequisites

## Learning objectives

By the end of this chapter, you'll:

- Understand the basic knowledge needed to follow this guide.
- Identify the tools you'll use throughout.
- Set up a workspace for writing and testing API documentation.

## Tools you'll need

The following tools and language will be used throughout this guide.

| Tool | Purpose |
|---|---|
| **[Visual Studio Code (VS Code)](https://code.visualstudio.com/download)** | Write and edit documentation. |
| **Markdown** | Format documentation using a simple, lightweight markup language. |
| **[Postman](https://www.postman.com/downloads/)** | Test API requests and inspect responses. |
| **[Git](https://git-scm.com/install/)** | Track changes to your documentation. |
| **[GitHub](https://docs.github.com/en/get-started)** | Store, manage, and collaborate on your documentation project. |
| **[Docusaurus](https://docusaurus.io/docs/installation)** | Build and publish the documentation website. |

If you don't have VS Code, Postman, Git, GitHub and Docusaurus installed, click the one you don't have and follow the link to download.

:::note

You don't need to be an expert in any of these tools before you begin. Each one will be introduced one after the other.

:::

## Industry-standard tools

As you continue learning API documentation, you'll come across other tools and specifications that are widely used across the industry.

| Tool | Purpose |
|---|---|
| **[OpenAPI Specification (OAS)](https://spec.openapis.org/oas/latest.html)** | A standard format for describing REST APIs. |
| **[Swagger Editor](https://editor.swagger.io/)** | Create and edit OpenAPI definition files. |
| **[Swagger UI](https://swagger.io/tools/swagger-ui/)** | Generate interactive API documentation from an OpenAPI definition. |

These tools are introduced later in the guide. For now, it's enough to know what they are and why they're commonly used.

## Key takeaways

Before moving to the next chapter, remember the following:

- Basic computer skills are enough to get started.
- Programming knowledge can be helpful, it is **not required**
- You'll use modern documentation tools throughout this guide.
- You'll learn each tool as it's introduced, so no prior experience is expected.

## Next steps

Now that your workspace is ready and you're familiar with the tools we'll be using, it's time to build a foundation in API concepts.

In the next chapter, you'll learn what an API is, why APIs exist, and how they enable different software applications to communicate with one another.

:::tip

Don't try to memorize every API term you encounter. Focus on understanding the purpose of each concept. As you practice with real APIs, terms like endpoints, headers, authentication, and JSON will become familiar naturally.

:::
