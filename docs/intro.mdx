# The Beginner's Guide to API Documentation

Welcome.

If you've ever wanted to learn API documentation but don't know where to start, you're in the right place.

This guide explains everything you need to know to write accurate and valuble API documentation. It is designed for beginner technical writers, documentation engineers, and developers.

You'll learn:

- API fundamentals
- Requests and responses
- Authentication
- JSON
- API documentation best practices
- Docs-as-code with Git, GitHub, Markdown, and Docusaurus

👉 To unlock your learning journey, begin with the **Introduction** in the **Getting started** section.
